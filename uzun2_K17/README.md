# Çekmecedeki eski cihaza yeni iş: 3 fikir

Videodaki örnekler kişisel paylaşımlardan geliyor; bağımsız doğrulanmadı. Aşağıdaki fikirler de başlangıç noktası, garanti değil.

## 3 fikir
- [ ] **Ev panosu:** Eski tableti duvara koy; hava durumu, takvim ve alışveriş listesini gösteren basit bir web sayfasını Claude'a yazdır.
- [ ] **Sorun giderme yardımcısı:** Modem ya da yazıcı sorun çıkardığında adımları tek tek soran küçük bir kontrol listesi sayfası hazırlat. Önce aç-kapat, sonra ışıklar, sonra kablo.
- [ ] **Dijital fotoğraf çerçevesi:** Seçtiğin bir klasördeki fotoğrafları sırayla gösteren sayfa. Fotoğraflar cihazda kalsın, internete yüklenmesin.

## Başlamadan
- [ ] Cihazı fabrika ayarına almadan önce içinde kalan kişisel dosyalara bak.
- [ ] Eski cihazın güvenlik güncellemesi almıyorsa onu yalnız ev ağında, hassas hesap açmadan kullan.

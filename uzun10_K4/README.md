# Token fiyatı: girdi maliyeti nasıl karşılaştırılır?

Video hazırlanırken geçerli girdi (input) fiyatları, 1 milyon token için:
- Jev: yaklaşık 4 cent
- Opus 5.5 (Anthropic, Claude modeli): 4 dolar
- Fable 5.1 (Anthropic, Claude modeli): 10 dolar

Videoda: Opus'a göre yaklaşık 95 kat, Fable'a göre yaklaşık 238 kat daha ucuz bir **girdi** maliyeti. Bu karşılaştırma yalnız girdi fiyatı.
Kaynaklar: https://openrouter.ai/compare/typesafe/jev-1.14 · https://flaviocopes.com/jev-pricing/

## Kendin hesapla
- [ ] **Token nedir?** Kabaca kelime parçası. Gönderdiğin yazı uzadıkça input token artar.
- [ ] **Input ve output ayrı fiyatlanır:** Modelin döndürdüğü cevap da output token olarak ayrıca fiyatlanır; güncel fiyatı kaynaktan kontrol et.
- [ ] **Basit hesap:** (gönderdiğin token sayısı / 1.000.000) × 1 milyon token fiyatı.
- [ ] **Fiyatlar değişir:** Karar vermeden önce güncel fiyat sayfasına bak.

# Jev bulutta, Clef senin sunucunda

- **Jev:** şimdilik yalnız TypeSafe'in sunucularında çalışıyor; indirip kendi bilgisayarına kuramıyorsun. Gönderdiğin her metin dışarı çıkıyor.
- **Clef:** benzer bir karar modeli; ağırlıkları açık, indirip kendi sunucunda çalıştırabiliyorsun. Jev'le aynı şekilde konuşacak biçimde tasarlanmış.

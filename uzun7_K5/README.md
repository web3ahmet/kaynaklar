# Hafıza klasörü: 4 temel dosya + kararlar klasörü

Videodaki klasörün en üstünde 4 temel dosya ve tarihli bir kararlar klasörü var. Hepsi düz yazı dosyası; Claude klasörü doğrudan okuyor, ek bir uygulama şart değil.

## Klasör yapısı
```
hafiza/
  kimlik.md        # ben kimim, ne yapıyorum, neyi asla unutmamalı
  kurallar.md      # her kural tek satır: kural · neden · tarih
  ozet-kartlari.md # son oturumların 3 satırlık özetleri
  acik-isler.md    # yarım kalan işler
  kararlar/
    2026-11-26-ornek-karar.md
```

## Şablonlar
- [ ] **kimlik.md:** "Ben … Şu işi yapıyorum … Asla unutma: …" (3-5 satır).
- [ ] **kurallar.md:** "- Kural. Neden: … (tarih)". Çelişen kural gelirse eskisini silme, üstünü çiz, yenisini yanına yaz.
- [ ] **ozet-kartlari.md:** "Ne yaptık / ne kaldı / sıradaki adım" (son 5 kart yeter, eskileri arşive).
- [ ] **acik-isler.md:** "- [ ] iş · neden bekliyor".
- [ ] **kararlar/tarih-konu.md:** karar, ne zaman, neden. Yeni oturumda aynı kararı baştan tartışmamak için.

## Uyarı
Şifreni, anahtarını bu klasöre koyma; kişisel notlarını ayrı tut.

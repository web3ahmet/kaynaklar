# Kendi hafıza klasörün: ilk hafta

Videodaki sistem düz yazı dosyalarından oluşan tek bir klasör. Kayıt anında 70 kural ve 252 kayıtlı hata vardı; sayılar her gün büyüyor. Hepsi küçük başladı.

## Başlangıç yapısı
```
hafiza/
  kimlik.md
  kurallar.md
  hata-defteri.md   # tarih · ne oldu · neden · bir daha olmasın diye ne yapıldı
```

## İlk hafta
- [ ] **1. gün:** kimlik.md'ye 3-5 satır yaz; Claude'a "her oturum başında bunu oku" de.
- [ ] **Her düzeltmede:** "bunu kurallara ekle" de; kural · neden · tarih.
- [ ] **Her hatada:** hata-defteri.md'ye tek satır: ne oldu, neden oldu.
- [ ] **Aynı hata 2. kez:** kural ekleme; Claude'dan onu ölçen küçük bir kontrol iste (ör. "konuşmada 0,33 saniyeden uzun boşluk var mı?" gibi sayıyla ölçülen bir kontrol).
- [ ] **Hafta sonu:** kurallar.md'yi oku; çelişenlerin üstünü çiz, silme.

## Uyarı
Şifreni, anahtarını bu klasöre koyma; kişisel notlarını ayrı tut.

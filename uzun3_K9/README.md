# Görsel modeli seçmek: iş listesi + 2 prompt

Sıralamalar sık değişir; güncelini buradan bak: https://arena.ai/leaderboard/text-to-image

## Hangi iş, neye bakarsın?
- [ ] **Afiş, üzerinde yazı olan görsel:** Yazıyı doğru basan modeli seç. Türkçe karakterleri (ş, ğ, ı) mutlaka dene.
- [ ] **Aynı karakter, farklı sahneler:** Referans görsel kabul eden ve karakteri koruyan modeli seç.
- [ ] **Hızlı fikir taslağı:** Ucuz ve hızlı model yeter; son hali sonra güçlü modelle yaparsın.
- [ ] **Ürün fotoğrafı:** Gerçekçi ışık ve doku veren modeli seç; gerçek ürünle karşılaştır.

## Prompt 1: Afiş
"Dikey bir etkinlik afişi tasarla. Üstte büyük harflerle 'YAZ ATÖLYESİ' yazsın, altında '12 Temmuz, Cumartesi'. Sade arka plan, iki renk, yazılar okunaklı ve hatasız olsun."

## Prompt 2: Karakter tutarlılığı
"Ekteki görseldeki karakteri koru: aynı yüz, aynı saç, aynı kıyafet. Onu bu kez bir kafede, masada kitap okurken çiz. Işık sabah ışığı olsun."

## Kontrol
- [ ] Yazılarda harf hatası var mı?
- [ ] Karakter ikinci görselde aynı kişi gibi duruyor mu?
